Инструкции по подключению Rate Cloud

Практические инструкции на русском языке. Выберите руководство для клиента или общий API-пример для другой OpenAI-совместимой программы.

  • OpenCode: ручная настройка формата OpenCode v1 и указания для v2.
  • Claude Code: настройка через переменные окружения и совместимый адрес Rate Cloud.
  • HTTP и Python: примеры curl и стандартной библиотеки Python без сторонних пакетов.
  • OpenClaw: собственный провайдер OpenAI Chat Completions с ключом из окружения.
  • Hermes Agent: настройка собственного API и переменной окружения для ключа.
  • DeepSeek Harness: собственный OpenAI Chat Completions API в веб-интерфейсе.
  • Continue: локальный YAML-каталог моделей и поддерживаемые ссылки на секреты.
  • Сравнение фиксированной стоимости: ценовые сценарии, условный курс, точка безубыточности и компромиссы сервиса.
  • 20 сценариев без суммарной квоты токенов: практические примеры и эксплуатационные ограничения.

Английская версия: Integration guides.
