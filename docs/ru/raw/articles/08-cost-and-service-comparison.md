# Rate Cloud и официальные API: фиксированная цена при постоянной нагрузке

Русский · [English](../../articles/08-cost-and-service-comparison.md)

**Преимущество Rate Cloud: фиксированная цена подписки без суммарной квоты токенов. С ростом использования цена подписки на модель не меняется.** API с оплатой за токены тарифицирует каждый оплачиваемый токен. При постоянной нагрузке на программирование, анализ и автоматизацию это может сделать Rate Cloud существенно дешевле, если рабочая нагрузка укладывается в её ограничения по скорости, параллельности, функциям и доступности.

При редком использовании Rate Cloud не обязательно дешевле. Официальные провайдеры предлагают скидки за кеширование, пакетные запросы, непиковые часы и другие условия. В сравнении показаны эти компромиссы. Проверено 3 ноября 2026 года; текущие цены не гарантируются в будущем.

## Тарифы официальных API и подписки Rate Cloud

Источники: [цены Z.ai](https://docs.z.ai/guides/overview/pricing), [цены DeepSeek и временные тарифы](https://api-docs.deepseek.com/quick_start/pricing/), [цены модели QwenCloud и точка подключения в Сингапуре](https://www.qwencloud.com/models/qwen3.8-max), [цены GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) и [каталог Rate Cloud](https://rate-cloud.com/).

Официальное API DeepSeek называет Flash `deepseek-flash` для версии V4.1-Flash-1017; Rate Cloud использует `deepseek-v4.1-flash`. Пиковые часы DeepSeek: 01:00-04:00 и 06:00-10:00 UTC с понедельника по пятницу, кроме государственных праздников Китая. В остальное время действует непиковый тариф. Строки GLM и DeepSeek сравнивают соответствующие модели. Qwen имеет общее название семейства, но функции хостинга и профили выполнения могут различаться. GPT рассматривается как альтернативный вариант для похожей работы, а не как идентичные веса, возможности или качество ответа.

## Стоимость при повторяющейся нагрузке

Предположим, что оплачиваемые токены состоят из 80% входных и 20% выходных, кеш не используется, а инструменты, пакетная обработка, налоги, специальные скидки и надбавка за длинный контекст отсутствуют. Токены рассуждения следует включать в оплачиваемый выход, если это применимо. Это **арифметические сценарии нагрузки**, а не фактическое использование клиентов или обещание, что Rate Cloud обработает такой объём за 30 дней.

| Официальный API | 10 млн всего | 100 млн | 500 млн | 1 млрд |
| --- | ---: | ---: | ---: | ---: |
| GLM-5.3 | $20 | $200 | $1 000 | $2 000 |
| GLM-5.3-Flash | $2,20 | $22 | $110 | $220 |
| DeepSeek Flash, непиковый/пиковый тариф | $2,40 / $4,80 | $24 / $48 | $120 / $240 | $240 / $480 |
| DeepSeek Pro, непиковый/пиковый тариф | $9,24 / $18,48 | $92,40 / $184,80 | $462 / $924 | $924 / $1 848 |
| Qwen3.8-Max | $28 | $280 | $1 400 | $2 800 |
| GPT-6.1 Sol Standard | $36 | $360 | $1 800 | $3 600 |

**Опубликованные цены подписки Rate Cloud на 30 дней остаются в диапазоне RUB 2 232-2 784 для всех этих сценариев объёма.** Это описание модели цены, а не гарантия обработки миллиарда токенов. Подписки на несколько моделей, дополнительные слоты, хостинг клиента, сервисы веб-поиска, вычисления CI и другие инструменты приложения могут увеличить расходы.

## Точка безубыточности вместо универсального обещания экономии

Для исключительно иллюстративного предположения о курсе **100 RUB за USD** 500 млн токенов без кеширования обойдутся в RUB 100 000 при использовании официального API GLM-5.3 против RUB 2 784 за подписку Rate Cloud GLM: стоимость доступа к модели примерно в 35,9 раза выше. При дешёвом непиковом API DeepSeek Flash та же арифметика даёт RUB 12 000 против RUB 2 442: примерно в 4,9 раза выше. Этот курс является предположением, а не текущей котировкой валюты; результат зависит от курса и нагрузки.

При таком предположении точка безубыточности для токенов без кеширования составляет примерно 13,92 млн токенов для GLM-5.3, 111 млн для GLM Flash, 101,75 млн для DeepSeek Flash в непиковые часы, 24,16 млн для DeepSeek Pro в непиковые часы и 9,11 млн для Qwen. Ниже соответствующего порога счёт по официальному API может быть меньше. Высокая доля попаданий в кеш повышает эти пороги.

Общая формула, объём в миллионах:

```text
средневзвешенная цена за миллион USD = доля входных * цена входа + доля выходных * цена выхода
точка безубыточности в миллионах = цена подписки RUB / (RUB за USD * средневзвешенная цена USD за миллион)
```

Пример чувствительности для DeepSeek Flash в непиковое время при попадании всего входа в кеш использует цену $0,003 за миллион входных и $0,60 за миллион выходных токенов: 500 млн при долях 80/20 стоят $61,20, а не $120. При условном курсе это RUB 6 120 против RUB 2 442. Реальное использование кеша не гарантировано, возможны расходы на запись в кеш и другие сборы. Qwen, Z.ai и OpenAI также публикуют скидки на кеширование; OpenAI предлагает более низкие ставки Batch/Flex и повышенные ставки за длинный контекст и режим Fast. Сравнивайте тариф, которым действительно будете пользоваться.

Воспроизведите сценарии офлайн с помощью [датированных данных о ценах](../data/pricing-2026-11-03.json) и [калькулятора](../tools/compare_costs.py):

```sh
python3 ru/tools/compare_costs.py --rub-per-usd 100 --million-tokens 500

```

## Компромиссы по скорости и сервису

Rate Cloud подходит, когда важнее предсказуемая стоимость постоянной нагрузки, чем минимальная задержка каждого ответа. Прямой API провайдера или тариф с приоритетом скорости может подойти лучше, если ваши измерения показывают меньшую задержку либо нужны хостинговые функции или договорные условия. Четыре слота Rate Cloud не равны лимитам параллельных запросов официальных API.

В этом репозитории **нет контролируемого теста скорости на одинаковых запросах и настройках рассуждений для всех этих сервисов**. Поэтому мы не публикуем выдуманные показатели токенов в секунду конкурентов и не заявляем измеренное универсальное превосходство по скорости. Опубликованный срез скорости Rate Cloud приведён в статье о [производительности](04-performance.md). Он учитывает ожидание и отличается от чистой скорости генерации токенов. В сравнении явно принимаются компромиссы задержки и ёмкости, но они не выдаются за установленный результат прямого теста.

Подписки на программные продукты провайдеров и бесплатные чаты отличаются от доступа к API с оплатой за токены. В таблице сравниваются указанные API, а не все планы провайдеров. Оценивайте качество задач и функции наряду с ценой.
