# Guias de integração da Rate Cloud

Instruções práticas de configuração para usuários da API da Rate Cloud. Escolha o guia do seu cliente ou use o guia genérico de API para outro aplicativo compatível com OpenAI.

- [OpenCode](opencode.md): configuração manual do provedor para OpenCode v1 e orientação para v2.
- [Claude Code](claude-code.md): configuração por ambiente para o endpoint compatível com Claude da Rate Cloud.
- [HTTP genérico e Python](http-python.md): exemplos sem dependências para curl e a biblioteca padrão do Python.
- [OpenClaw](openclaw.md): provedor personalizado de Chat Completions com credenciais do ambiente.
- [Hermes Agent](hermes-agent.md): configuração do endpoint personalizado e variável de ambiente da chave.
- [DeepSeek Harness](deepseek-harness.md): modelo OpenAI Chat Completions personalizado pela interface web.
- [Continue](continue.md): catálogo local de modelos YAML com referências de segredo compatíveis com o Continue.
- [Comparação de custos com preço fixo](../articles/08-cost-and-service-comparison.md): tarifas publicadas em USD, ponto de equilíbrio e compensações do serviço.
- [20 fluxos com tokens ilimitados](../articles/09-unlimited-use-cases.md): exemplos práticos e limites operacionais.

Versões em outros idiomas: [English](../../guides/README.md) · [Русский](../../ru/guides/README.md) · [Español](../../es/guides/README.md).

Os exemplos foram preparados com base na [documentação oficial de conexão da Rate Cloud](https://rate-cloud.com/docs), consultada em 3 de novembro de 2026. Se o formato de algum cliente mudar, siga as instruções atuais do painel. Nenhum exemplo contém uma chave de API real e os comandos não instalam programas.
