Guías de integración de Rate Cloud

Instrucciones prácticas de configuración para usuarios de la API de Rate Cloud. Elige la guía de tu cliente o usa la guía genérica de API para otra aplicación compatible con OpenAI.

  • OpenCode: configuración manual del proveedor para OpenCode v1 y orientación para v2.
  • Claude Code: configuración mediante el entorno para el endpoint compatible con Claude de Rate Cloud.
  • HTTP genérico y Python: ejemplos sin dependencias externas para curl y la biblioteca estándar de Python.
  • OpenClaw: proveedor personalizado Chat Completions con credenciales desde el entorno.
  • Hermes Agent: configuración de endpoint personalizado y variable de entorno para la clave.
  • DeepSeek Harness: modelo OpenAI Chat Completions personalizado desde la interfaz web.
  • Continue: catálogo local de modelos YAML con referencias de secretos compatibles con Continue.
  • Comparación de costes a precio fijo: tarifas publicadas en USD, punto de equilibrio y condiciones del servicio.
  • 20 flujos con tokens ilimitados: ejemplos prácticos y límites operativos.

Versiones en otros idiomas: English · Русский · Português.

Los ejemplos se prepararon a partir de la documentación oficial de conexión de Rate Cloud, consultada el 3 de noviembre de 2026. Si cambia el formato de un cliente compatible, sigue las instrucciones vigentes del panel. Ningún ejemplo contiene una clave de API real y los comandos no instalan programas.
