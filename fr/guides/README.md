# Guides d’intégration Rate Cloud

Instructions pratiques en français pour utiliser l’API Rate Cloud. Choisissez votre client ou le guide API général pour une autre application compatible avec OpenAI.

- [OpenCode](opencode.md) : configuration manuelle d’OpenCode v1 et indications pour v2.
- [Claude Code](claude-code.md) : configuration par variables d’environnement pour le point d’accès compatible Claude.
- [HTTP et Python](http-python.md) : exemples avec curl et la bibliothèque standard Python.
- [OpenClaw](openclaw.md) : fournisseur personnalisé avec Chat Completions.
- [Hermes Agent](hermes-agent.md) : point d’accès personnalisé et secret local.
- [DeepSeek Harness](deepseek-harness.md) : configuration d’une API de modèle personnalisée.
- [Continue](continue.md) : configuration YAML et résolution locale des secrets.

Autres langues : [English](../../guides/README.md) · [Deutsch](../../de/guides/README.md) · [Русские инструкции](../../ru/guides/README.md).

Les exemples ont été préparés d’après la [documentation officielle de connexion Rate Cloud](https://rate-cloud.com/docs), vérifiée le 3 novembre 2026. Si le format client pris en charge évolue, suivez les consignes actuelles de l’espace client. Aucun exemple ne contient de vraie clé API ni n’installe de logiciel.
