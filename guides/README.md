# Rate Cloud integration guides

Practical English setup instructions for Rate Cloud API users. Start with the guide for your client, or use the generic API guide for another OpenAI-compatible application.

- [OpenCode](opencode.md): manual provider setup for OpenCode v1, plus version guidance for v2.
- [Claude Code](claude-code.md): environment-based setup for the Rate Cloud Claude-compatible endpoint.
- [Generic HTTP and Python](http-python.md): key-free examples for curl and Python's standard library.

Russian translations: [Русские инструкции](../ru/guides/README.md).

The examples were prepared against the [official Rate Cloud connection documentation](https://rate-cloud.com/docs), checked November 3, 2026. Follow the live dashboard instructions if its supported client format changes. No example contains a real API key, and none of the commands shown here installs software.
