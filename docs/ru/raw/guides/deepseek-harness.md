# Подключение DeepSeek Harness к Rate Cloud

В DeepSeek Harness есть документированная форма **Custom model API** для OpenAI-совместимых шлюзов. Rate Cloud публикует OpenAI-совместимый Chat Completions API. Ниже используются этот протокол и ручное добавление ID моделей.

**Документация проверена:** 3 ноября 2026 года. DeepSeek Harness указывает, что это предварительная версия для разработчиков с несовместимыми изменениями. Инструкция основана на опубликованной документации Web UI Harness и Rate Cloud. Это статическое сопоставление, интеграция не проверялась живым запросом. Установщик и API-запросы не запускались.

Официальные источники: [инструкция Rate Cloud](https://rate-cloud.com/docs), [репозиторий и предупреждение о preview DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), [настройка моделей в DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/en/guide/providers), [краткий старт DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart) и [каталог конфигурации плагинов](https://deepseek-harness.github.io/deepseek-harness/en/reference/config-catalog).

## Граница совместимости

Rate Cloud публикует следующие адреса и прямые ID моделей:

| Назначение | Значение |
| --- | --- |
| Базовый адрес | `https://llm.rate-cloud.com/v1` |
| Маршрут Chat Completions | `POST /v1/chat/completions` |
| GLM 5.3 | `glm-5.3` |
| GLM 5.3 Flash | `glm-5.3-flash` |
| DeepSeek V4.1 Flash | `deepseek-v4.1-flash` |
| DeepSeek V4 Pro | `deepseek-v4-pro` |
| Qwen 3.8 Max | `qwen-3.8-max` |

В Harness собственный провайдер настраивается базовым адресом, протоколом, учётными данными и списком моделей. Для этого API выберите **OpenAI Chat Completions**. Не выбирайте для примера Responses или Anthropic Messages. Опубликованная документация не подтверждает наличие встроенного провайдера Rate Cloud в Harness и не содержит проверки живой интеграции.

## Настройте права аккаунта и ключа

В кабинете Rate Cloud создайте ключ, разрешите нужную модель и проверьте пробный доступ или подписку аккаунта. Полный секрет показывается только один раз. Наличие модели в каталоге не означает, что ключу разрешены запросы к ней.

## Добавьте собственный API в Web UI

Это инструкция по настройке через UI. Она не устанавливает программу и не отправляет запрос к модели.

1. Запустите Web UI Harness по инструкции в официальном README. Установочные команды здесь не приводятся.
2. Откройте **Settings → Models**, затем выберите **Add model provider**.
3. Переключите форму в режим **Custom model API**.
4. Укажите ID провайдера строчными буквами, например `ratecloud`. В Harness этот ID постоянный: на него ссылаются запросы, сессии, значения по умолчанию и учётные данные.
5. Введите отображаемое имя `Rate Cloud` и Base URL `https://llm.rate-cloud.com/v1`.
6. В качестве протокола API выберите **OpenAI Chat Completions**.
7. Введите ключ Rate Cloud в поле учётных данных формы. По документации Harness сохранённый ключ доступен в UI только для записи; он хранится в `$DSH_HOME/.credentials.yaml`, а в настройках остаётся ссылка на секрет. Не помещайте ключ в репозиторий или публичное обращение.
8. Вручную добавьте модель по одному из точных ID из таблицы и задайте ей понятное отображаемое имя. Не указывайте размер контекста, максимальный вывод, поддержку изображений или рассуждений без подтверждённых значений и возможностей модели.
9. Сохраните провайдера, затем выберите его модель в списке моделей, чтобы она стала моделью по умолчанию для новых сессий.

К одному провайдеру можно добавить другие модели по их точным базовым ID. Не добавляйте к ID префикс клиента `ratecloud/` в форме собственного API.

## Необязательное обнаружение моделей

Harness умеет запрашивать каталог моделей у API, используя указанные URL, протокол и секрет. Это действие отправляет аутентифицированный HTTP-запрос. Обнаружение необязательно и поддерживается не для всех форматов списка. Чтобы настроить без запроса, добавьте ID вручную, как описано выше. При подготовке руководства запрос обнаружения не выполнялся.

## Если не работает

- **`MISSING_CREDENTIAL`:** проверьте, что для провайдера сохранён ключ или доступна заданная ссылка на секрет.
- **`UNKNOWN_MODEL`:** добавьте точный ID в список моделей провайдера и выберите эту запись. Проверьте строчные буквы, точки и дефисы.
- **HTTP 401:** проверьте ключ, его срок действия и разрешения модели в Rate Cloud. Список моделей не является проверкой доступа.
- **HTTP 404 или неправильный маршрут:** укажите `https://llm.rate-cloud.com/v1` как Base URL и выберите OpenAI Chat Completions. Не добавляйте `/chat/completions` в Base URL.
- **Обнаружение моделей не показывает записи:** формат каталога может быть не распознан Harness. Добавьте ID вручную; ошибка обнаружения не доказывает, что генерация недоступна.
- **Не работают инструменты, изображения или рассуждения:** указание возможности в Harness не создаёт и не проверяет её поддержку API. Настраивайте только те функции, которые подтверждены документацией выбранной модели и проверкой совместимости.
- **Путь или форма настроек отличаются:** Harness находится в preview и быстро меняется. Сверяйтесь с текущей страницей настройки моделей и каталогом конфигурации плагинов для установленной версии.

Живые запросы не выполнялись, поэтому авторизация и поведение функций в Harness не подтверждены.
