Guias de integração da Rate Cloud

Instruções práticas de configuração para usuários da API da Rate Cloud. Escolha o guia do seu cliente ou use o guia genérico de API para outro aplicativo compatível com OpenAI.

  • OpenCode: configuração manual do provedor para OpenCode v1 e orientação para v2.
  • Claude Code: configuração por ambiente para o endpoint compatível com Claude da Rate Cloud.
  • HTTP genérico e Python: exemplos sem dependências para curl e a biblioteca padrão do Python.
  • OpenClaw: provedor personalizado de Chat Completions com credenciais do ambiente.
  • Hermes Agent: configuração do endpoint personalizado e variável de ambiente da chave.
  • DeepSeek Harness: modelo OpenAI Chat Completions personalizado pela interface web.
  • Continue: catálogo local de modelos YAML com referências de segredo compatíveis com o Continue.
  • Comparação de custos com preço fixo: tarifas publicadas em USD, ponto de equilíbrio e compensações do serviço.
  • 20 fluxos com tokens ilimitados: exemplos práticos e limites operacionais.

Versões em outros idiomas: English · Русский · Español.

Os exemplos foram preparados com base na documentação oficial de conexão da Rate Cloud, consultada em 3 de novembro de 2026. Se o formato de algum cliente mudar, siga as instruções atuais do painel. Nenhum exemplo contém uma chave de API real e os comandos não instalam programas.
