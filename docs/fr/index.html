Les cinq modèles actuels dans un seul forfait.

Un pack : $45.45 / 30 jours, $22.72 / 7 jours ou $13.63 / 3 jours. Un code de 10 % réduit les prix à $40.90, $20.45 et $12.27, selon le taux public du 3 nov. 2026.

Un emplacement par modèle et par pack. Les quantités s’additionnent pour tous les modèles sans transfert possible. Deux packs autorisent deux requêtes simultanées par modèle. Les achats supplémentaires ajoutent des emplacements ; renouveler la quantité choisie prolonge la durée sans changer les emplacements. Les abonnements individuels sont indépendants. Les offres du premier achat suivent les règles habituelles. Le renouvellement manuel constitue une nouvelle commande et peut utiliser un code promo ou des bonus si le compte respecte les règles habituelles d’éligibilité. Le renouvellement automatique via Whop est facturé au plein tarif convenu, sans répéter la remise de bienvenue.
