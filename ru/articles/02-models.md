# Модели и выбор подходящей

[English](../../articles/02-models.md) · Русский

В опубликованном каталоге Rate Cloud пять моделей. Для каждой доступна отдельная подписка и точный идентификатор для прямых HTTP-запросов. Выбирайте модель под нужную задачу и проверяйте её на типичных входных данных.

**Full model: коммерческий пакет из этих пяти нативных API-моделей, а не шестая модель или API ID.** Каждый пакет добавляет по одному параллельному слоту каждой модели ниже. Количество пакетов одинаково для всех пяти моделей, слоты нельзя перераспределять, поэтому два пакета дают по два параллельных слота на модель. Подробнее: [условия и цены Full model](01-about-rate-cloud.md).

## Как подобрать модель под рабочий процесс

GLM 5.3 предназначена для продолжительной работы над сложными программными проектами, анализа репозиториев, использования инструментов и координации субагентов. GLM 5.3 Flash рассчитана на повторяющиеся повседневные задачи и автоматизацию с большим количеством отдельных вызовов.

DeepSeek V4.1 Flash предназначена для генерации и изменения кода, агентов программирования и рабочих нагрузок с большим числом программных задач. DeepSeek V4 Pro ориентирована на рассуждения и глубокий анализ, включая архитектурные решения и проверки, где качество ответа важнее минимальной задержки.

Qwen 3.8 Max позиционируется для больших объёмов материала, включая репозитории и документы. Указание на длинный контекст не является числовой спецификацией размера контекстного окна. Перед проектированием рабочих процессов с большими входными данными проверьте действующую документацию и фактические ограничения запросов.

Это примеры сценариев применения продукта, а не универсальный рейтинг или гарантия, что одна модель лучше справится с любой задачей. При оценке учитывайте правильность выполнения, соблюдение инструкций, работу вызовов инструментов, требования к изображениям, время ответа и объём ручных исправлений.

## Идентичность модели и профиль выполнения

Для одной модели может быть доступно несколько одобренных профилей точности. Маршрутизатор выбирает подходящий профиль запрошенной пользователем модели. Выбор компактного профиля выполнения не означает замену запрошенной модели другой позицией каталога. Flash и Pro являются разными моделями.

Для прямого API используйте точные ID из таблицы. В названиях моделей для отдельных клиентов может присутствовать префикс провайдера, который не входит в идентификатор прямого HTTP API. Наличие модели в списке клиента само по себе не подтверждает, что аккаунту или ключу разрешено её запускать.
