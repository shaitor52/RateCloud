### План Full model

Full model включает все пять текущих моделей и по одному параллельному слоту на каждую. Стоимость: 3 680 ₽ за 30 дней, 1 840 ₽ за 7 дней или 1 104 ₽ за 3 дня; промокод 10% снижает её до 3 312 ₽, 1 656 ₽ и 993,60 ₽. Количество пакетов задаёт одинаковое число слотов для каждой модели, их нельзя перераспределить: два пакета дают по два одновременных запроса к каждой модели. Дополнительная покупка Full model добавляет слоты, а продление выбранного количества пакетов продлевает срок без изменения их числа. Отдельные подписки сохраняют собственную параллельность. При первой покупке действуют стандартные правила промокодов, реферальной скидки и бонусов. Ручное продление оформляется новым заказом и может использовать промокод или бонусы, если аккаунт соответствует обычным правилам их доступности. Автоматическое продление через Whop оплачивается по полной согласованной цене без повторной вводной скидки. Перед оплатой проверьте актуальный итог заказа.

## Начало работы с Rate Cloud

1. Перейдите на [rate-cloud.com](https://rate-cloud.com/) и откройте кабинет.
2. Зарегистрируйтесь и подтвердите электронную почту и адрес Telegram для пробного доступа.
3. Выберите модель, создайте API-ключ и подключите совместимое приложение.
4. Используйте [официальное руководство по подключению](https://rate-cloud.com/docs), чтобы узнать актуальные шаги настройки.

Опубликованный пробный доступ позволяет тестировать модели в течение первых трёх часов после необходимых подтверждений, с одним одновременным слотом. У платного доступа другие сроки подписки и лимиты параллельности.
