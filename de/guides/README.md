# Integrationsanleitungen für Rate Cloud

Praktische Anleitungen auf Deutsch für die Rate-Cloud-API. Wählen Sie den Client oder verwenden Sie die allgemeine API-Anleitung für andere OpenAI-kompatible Anwendungen.

- [OpenCode](opencode.md): manuelle Einrichtung für OpenCode v1 und Hinweise zu v2.
- [Claude Code](claude-code.md): Einrichtung über Umgebungsvariablen für den Claude-kompatiblen Endpunkt.
- [HTTP und Python](http-python.md): Beispiele mit curl und der Python-Standardbibliothek.
- [OpenClaw](openclaw.md): eigener Anbieter mit Chat Completions.
- [Hermes Agent](hermes-agent.md): eigener Endpunkt und Schlüssel aus der lokalen Umgebung.
- [DeepSeek Harness](deepseek-harness.md): Konfiguration eines eigenen Modell-API-Anbieters.
- [Continue](continue.md): YAML-Konfiguration und lokale Geheimnisauflösung.

Weitere Sprachen: [English](../../guides/README.md) · [Français](../../fr/guides/README.md) · [Русские инструкции](../../ru/guides/README.md).

Die Beispiele wurden anhand der [offiziellen Rate-Cloud-Verbindungsdokumentation](https://rate-cloud.com/docs) geprüft, Stand 3. November 2026. Wenn sich das unterstützte Clientformat ändert, folgen Sie den aktuellen Dashboard-Anweisungen. Die Beispiele enthalten keinen echten API-Schlüssel und installieren keine Software.
