# Подключение OpenCode к Rate Cloud

Это руководство настраивает OpenCode для OpenAI-совместимого API Rate Cloud. Здесь приведён документированный формат конфигурации OpenCode v1. В актуальной инструкции Rate Cloud отдельно указаны форматы v1 и v2. Для v2 используйте текущий пример v2 в кабинете, не вставляйте туда конфигурацию v1.

Официальные источники: [инструкция Rate Cloud](https://rate-cloud.com/docs) и [документация конфигурации OpenCode](https://opencode.ai/docs/config/).

## Перед началом

1. Войдите в Rate Cloud и создайте API-ключ в разделе **Настройки → API-ключи**. Скопируйте его сразу: полный секрет показывается только при создании.
2. Убедитесь, что ключу разрешена нужная модель, а у аккаунта есть пробный доступ или активная подписка на неё. Наличие модели в списке не означает право выполнять запросы.
3. В конфигурации OpenCode v1 используется префикс `ratecloud/` при выборе настроенного провайдера. Это префикс клиента. В прямом HTTP API передаётся ID модели без него.

Точные ID прямого API:

| Модель | ID прямого API | Выбор в OpenCode v1 |
| --- | --- | --- |
| GLM 5.3 | `glm-5.3` | `ratecloud/glm-5.3` |
| GLM 5.3 Flash | `glm-5.3-flash` | `ratecloud/glm-5.3-flash` |
| DeepSeek V4.1 Flash | `deepseek-v4.1-flash` | `ratecloud/deepseek-v4.1-flash` |
| DeepSeek V4 Pro | `deepseek-v4-pro` | `ratecloud/deepseek-v4-pro` |
| Qwen 3.8 Max | `qwen-3.8-max` | `ratecloud/qwen-3.8-max` |

## Задайте ключ в окружении

Ниже приведены варианты для Bash и zsh (оболочка по умолчанию в macOS). Ввод ключа не отображается в терминале. Вставьте секрет в ответ на приглашение. Переменная будет доступна программам, запущенным из этой оболочки. Закройте терминал или удалите переменную командой `unset`.

```sh
# Bash
read -r -s -p 'API-ключ Rate Cloud: ' RATE_CLOUD_API_KEY
printf '\n'
export RATE_CLOUD_API_KEY
```

```sh
# zsh
read -r -s 'RATE_CLOUD_API_KEY?API-ключ Rate Cloud: '
printf '\n'
export RATE_CLOUD_API_KEY
```

Не вставляйте ключ в общий файл конфигурации, репозиторий, снимок экрана или обращение в поддержку. В Windows задайте `RATE_CLOUD_API_KEY` в окружении, из которого запускаете OpenCode, используя привычный безопасный способ хранения секрета.

## Настройте OpenCode v1

Откройте существующий файл конфигурации OpenCode: `~/.config/opencode/opencode.json` в macOS/Linux. Сохраните остальные провайдеры и параметры. Объедините запись `provider` ниже с существующим объектом, затем задайте или объедините верхнеуровневое поле `model`. Если файла ещё нет, это полный минимальный пример для GLM 5.3:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "ratecloud/glm-5.3",
  "provider": {
    "ratecloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Rate Cloud",
      "options": {
        "baseURL": "https://llm.rate-cloud.com/v1",
        "apiKey": "{env:RATE_CLOUD_API_KEY}"
      },
      "models": {
        "glm-5.3": { "name": "GLM 5.3" },
        "glm-5.3-flash": { "name": "GLM 5.3 Flash" },
        "deepseek-v4.1-flash": { "name": "DeepSeek V4.1 Flash" },
        "deepseek-v4-pro": { "name": "DeepSeek V4 Pro" },
        "qwen-3.8-max": { "name": "Qwen 3.8 Max" }
      }
    }
  }
}
```

OpenCode подставляет `{env:RATE_CLOUD_API_KEY}` из окружения при загрузке конфигурации. Если переменная не задана, она заменяется пустой строкой. Поэтому экспортируйте ключ до запуска OpenCode. В конфигурации хранится ссылка на переменную, а не сам секрет.

В Windows документированный путь пользовательской конфигурации: `%USERPROFILE%\.config\opencode\opencode.json`. В OpenCode v1 и v2 разные структуры провайдера. Для OpenCode v2 используйте отдельный пример v2 из кабинета Rate Cloud. Не адаптируйте пример v1 наугад.

## Выберите модель и проверьте подключение

После изменения конфигурации перезапустите OpenCode, откройте список моделей (`/models` в TUI) и выберите модель `Rate Cloud`. Начните с короткого запроса без конфиденциального содержимого. Выбирайте точное имя из столбца OpenCode v1.

## Если не работает

- **Rate Cloud отсутствует в списке:** проверьте, что конфигурация сохранена по пути для вашей ОС и JSON корректен. Проверьте расположение `provider.ratecloud` и `model` на верхнем уровне.
- **Ошибка авторизации или отказ:** проверьте, что `RATE_CLOUD_API_KEY` экспортирован в той же оболочке, из которой запущен OpenCode. В кабинете проверьте срок ключа, IP-ограничения, доступ ключа к модели и наличие пробной или платной подписки.
- **Ключ будто пустой:** OpenCode заменяет незаданную переменную окружения пустой строкой. Задайте её до запуска и перезапустите клиент.
- **Отказ по модели:** используйте точный ID строчными буквами, включая точки и дефисы. Проверьте, что у ключа и аккаунта есть доступ. Появление модели в каталоге само по себе не подтверждает доступ.
- **У вас OpenCode v2:** используйте его формат `providers` из кабинета. Не вставляйте пример v1 с полем `provider` в файл v2.

При обращении в поддержку укажите версию клиента, операционную систему, ID модели, время и текст ошибки. Удалите API-ключи, заголовки авторизации и личное содержимое запросов.
