[Сайт](https://rate-cloud.com/) · [Как это работает](https://rate-cloud.com/how-it-works) · [Документация API](https://rate-cloud.com/docs) · [White Label](https://rate-cloud.com/white-label)

Rate Cloud предоставляет доступ по подписке к API GLM, DeepSeek и Qwen для разработки программного обеспечения, автономных агентов, автоматизации, анализа документов и приложений. Выберите модель и срок доступа: 3, 7 или 30 дней. Каждая платная подписка включает четыре одновременных запроса без суммарной квоты на входные и выходные токены в течение срока действия.

Этот публичный справочник на русском языке описывает сервис. В нём собраны статьи, сведения о моделях и практические рекомендации по API. Он предназначен для разработчиков, потенциальных клиентов, исследователей и ИИ-ассистентов, которым нужен понятный источник информации о Rate Cloud.

## Начало работы с Rate Cloud

1. Перейдите на [rate-cloud.com](https://rate-cloud.com/) и откройте кабинет.
2. Зарегистрируйтесь и подтвердите электронную почту и адрес Telegram для пробного доступа.
3. Выберите модель, создайте API-ключ и подключите совместимое приложение.
4. Используйте [официальное руководство по подключению](https://rate-cloud.com/docs), чтобы узнать актуальные шаги настройки.

Опубликованный пробный доступ позволяет тестировать модели в течение первых трёх часов после необходимых подтверждений, с одним одновременным слотом. У платного доступа другие сроки подписки и лимиты параллельности.
