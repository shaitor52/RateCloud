# Подключение Hermes Agent к Rate Cloud

Hermes Agent поддерживает собственные OpenAI-совместимые API. В этом руководстве используется документированная конфигурация собственного провайдера Hermes и совместимый с OpenAI адрес `/v1` Rate Cloud для Chat Completions.

**Документация проверена:** 3 ноября 2026 года. Примеры соответствуют опубликованным инструкциям Hermes и Rate Cloud, но не проверялись живой установкой Hermes Agent или аккаунтом. Документация Hermes обновляется; на просмотренных страницах не указана минимальная версия Hermes для этой настройки. Конфигурация провайдеров менялась, поэтому ниже используются текущие имена полей.

Официальные источники: [инструкция Rate Cloud](https://rate-cloud.com/docs), [раздел провайдеров Hermes Agent](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/integrations/providers.md), [переменные окружения Hermes](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/reference/environment-variables.md) и [файлы конфигурации Hermes](https://hermes-agent.nousresearch.com/docs).

## Подготовьте доступ

Создайте API-ключ в кабинете Rate Cloud, разрешите ему нужную модель и проверьте активный пробный доступ или подписку. Полный ключ показывается только при создании. Не храните его в исходном коде и не отправляйте в поддержку.

Общий совместимый адрес Rate Cloud:

```text
https://llm.rate-cloud.com/v1
```

Используйте прямой ID модели без префикса. Для Hermes не нужен префикс `ratecloud/`, используемый некоторыми другими клиентами.

| Модель | ID прямого API |
| --- | --- |
| GLM 5.3 | `glm-5.3` |
| GLM 5.3 Flash | `glm-5.3-flash` |
| DeepSeek V4.1 Flash | `deepseek-v4.1-flash` |
| DeepSeek V4 Pro | `deepseek-v4-pro` |
| Qwen 3.8 Max | `qwen-3.8-max` |

## Сохраните секрет в локальном файле окружения Hermes

В актуальной документации Hermes пользовательские секреты хранятся в `~/.hermes/.env`. Добавьте эту строку локально, заменив заполнитель на свой ключ:

```dotenv
RATE_CLOUD_API_KEY=<ваш-ключ>
```

В Windows используйте `%USERPROFILE%\.hermes\.env`. Не добавляйте файл в репозиторий и не вставляйте настоящий ключ в общий пример. Hermes также читает переменную из окружения процесса; поле `key_env` ниже указывает её имя.

## Настройте собственный адрес API

Измените `~/.hermes/config.yaml` в macOS/Linux или `%USERPROFILE%\.hermes\config.yaml` в Windows. Объедините эти параметры с существующей секцией `model`, не стирая остальные настройки:

```yaml
model:
  default: glm-5.3
  provider: custom
  base_url: https://llm.rate-cloud.com/v1
  key_env: RATE_CLOUD_API_KEY
```

Используются документированные для Hermes поля собственного API: `provider: custom`, `base_url` и `key_env`. API работает через Chat Completions; не меняйте его на транспорт Anthropic Messages или Responses. Не указывайте размер контекста без проверенного значения для сервиса и модели.

Чтобы выбрать другую модель Rate Cloud, замените `model.default` точным ID из таблицы. Оставьте `provider: custom` и базовый адрес Rate Cloud.

## Необязательная интерактивная настройка

В документации Hermes команда `hermes model` открывает мастер для собственного API. Он запрашивает базовый адрес, API-ключ и модель, затем сохраняет выбор. Если используете мастер, укажите `https://llm.rate-cloud.com/v1` и ID без префикса из таблицы. Ручная настройка выше предпочтительна, если вы не хотите сохранять буквальный ключ в `config.yaml`.

## Если не работает

- **Нет учётных данных:** проверьте, что `RATE_CLOUD_API_KEY` задан в `~/.hermes/.env` или окружении процесса, а имя в `key_env` совпадает с ним.
- **Ошибка соединения:** укажите базовый адрес с `/v1`, но без `/v1/chat/completions`. Клиент добавляет путь API сам.
- **Неизвестная модель или отказ доступа:** укажите точный прямой ID. В кабинете проверьте разрешённые модели ключа и пробный доступ или подписку.
- **Вызовы инструментов возвращаются обычным текстом:** OpenAI-совместимый транспорт не гарантирует, что любая модель и любой API поддерживают вызовы инструментов в формате агента. Проверьте реальные возможности модели, прежде чем полагаться на инструменты.
- **Неверно определяется контекст:** Hermes может читать сведения из `/v1/models`, но документация не гарантирует наличие всех параметров в этом каталоге. Не вписывайте непроверенный размер контекста.
- **Нашёлся старый пример:** в прежней документации могут встречаться `api_key` и другая схема. Сверьте поля с текущим руководством Hermes и версией установленного клиента.

При подготовке руководства не запускались API-запросы и установщики.
