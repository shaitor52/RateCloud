# Подключение инструментов и приложений к Rate Cloud

[English](../../articles/05-api-and-integrations.md) · Русский

Rate Cloud предоставляет HTTP API, совместимый с OpenAI, и отдельные совместимые эндпоинты для поддерживаемых клиентов программирования. В кабинете опубликованы инструкции по настройке для конкретных приложений. Используйте инструкции для установленной версии клиента и операционной системы.

## Опубликованные эндпоинты

| Назначение | Эндпоинт |
| --- | --- |
| Базовый URL API, совместимого с OpenAI | `https://llm.rate-cloud.com/v1` |
| Каталог моделей | `GET https://llm.rate-cloud.com/v1/models` |
| Chat Completions | `POST https://llm.rate-cloud.com/v1/chat/completions` |
| Responses | `POST https://llm.rate-cloud.com/v1/responses` |
| Базовый URL совместимости с Codex | `https://llm.rate-cloud.com/codex/v1` |
| Базовый URL совместимости с Claude Code | `https://llm.rate-cloud.com/claude` |

Прямые запросы к `/v1` используют bearer API-ключ для аутентификации. Укажите точный ID модели из [каталога](02-models.md), например `glm-5.3`. Не добавляйте к идентификатору прямого HTTP API клиентский префикс `ratecloud/`.

## От регистрации до первого запроса

Зарегистрируйтесь или войдите через [Rate Cloud](https://rate-cloud.com/). Для пробного доступа пройдите необходимые подтверждения, либо оформите подписку на нужную модель. В настройках API-ключей кабинета создайте именованный ключ, выберите доступные для него модели, разрешённые IP-адреса и срок действия, затем сразу скопируйте показанный секрет.

Подписка даёт право запускать модель, а разрешения ключа определяют, может ли конкретный ключ использовать это право. Ключ с доступом только к выбранным моделям автоматически не получит доступ к новой купленной модели. Наличие модели в списке не доказывает, что у вас есть доступ к её запуску.

Для Codex или Claude Code в публичном руководстве предлагается включить для ключа совместимость Codex / Claude Code.

## Минимальный HTTP-запрос

Задайте `RATE_CLOUD_API_KEY` в локальном окружении удобным для вас способом хранения секрета, затем выполните команду:

```sh
curl --fail-with-body https://llm.rate-cloud.com/v1/chat/completions \
  -H "Authorization: Bearer $RATE_CLOUD_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"model":"glm-5.3","messages":[{"role":"user","content":"Reply with a short greeting."}]}'
```

Указанная переменная является заполнителем для вашего локального секрета. Никогда не помещайте настоящий ключ в публичный репозиторий, снимок экрана, обращение в поддержку или сохранённую конфигурацию клиента. Сначала проверьте идентификаторы через эндпоинт каталога моделей, затем выполните небольшой запрос к модели, доступной вашему аккаунту и ключу.

## Клиенты программирования и другие приложения

В публичном руководстве по подключению описаны OpenCode, Codex, Claude Code, OpenClaw, Continue, Hermes и другие совместимые клиенты. В кабинете приведены команды автоматической установки и примеры ручной настройки для поддерживаемых операционных систем.

Настройка клиента зависит от его версии. Например, официальное руководство различает форматы конфигурации OpenCode v1 и v2. Используйте текущие инструкции кабинета, а не устаревший пример конфигурации из сторонней статьи.

Клиент предоставляет интерфейс редактора или терминала, локальные инструменты, подключения MCP, инструкции проекта и управление беседами. Доступные функции модели зависят как от выбранной модели, так и от интеграции. Совместимый эндпоинт не означает, что доступны все функции любого API первой стороны.

## Устранение проблем без раскрытия секретов

Проверьте базовый URL и точный идентификатор модели, активную подписку или пробный доступ, разрешения ключа для модели, срок действия, ограничения по IP и параметр совместимости, если он требуется. При одновременных запросах учитывайте общий пул слотов. При обращении в поддержку укажите время и идентификатор запроса, удалив заголовки авторизации и личное содержимое запроса.
