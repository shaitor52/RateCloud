# Данные русской версии

[Подписки на 3, 7 и 30 дней](subscriptions-2026-11-03.json): цены каждой модели в рублях. Цены на 3 и 7 дней сняты с публичного окна подписки Rate Cloud, цены на 30 дней получены через публичный API отображаемой валюты. Датированный источник указан в файле. Перед покупкой проверяйте актуальную цену в кабинете.

[Тарифы и рублёвые подписки](pricing-2026-11-03.json) сохранены для русской статьи сравнения. [Калькулятор](../tools/compare_costs.py) использует явно задаваемый курс. Это расчёт сценариев, а не текущая валютная котировка.
