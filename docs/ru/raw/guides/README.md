# Инструкции по подключению Rate Cloud

Практические инструкции на русском языке. Выберите руководство для клиента или общий API-пример для другой OpenAI-совместимой программы.

- [OpenCode](opencode.md): ручная настройка формата OpenCode v1 и указания для v2.
- [Claude Code](claude-code.md): настройка через переменные окружения и совместимый адрес Rate Cloud.
- [HTTP и Python](http-python.md): примеры curl и стандартной библиотеки Python без сторонних пакетов.
- [OpenClaw](openclaw.md): собственный провайдер OpenAI Chat Completions с ключом из окружения.
- [Hermes Agent](hermes-agent.md): настройка собственного API и переменной окружения для ключа.
- [DeepSeek Harness](deepseek-harness.md): собственный OpenAI Chat Completions API в веб-интерфейсе.
- [Continue](continue.md): локальный YAML-каталог моделей и поддерживаемые ссылки на секреты.
- [Сравнение фиксированной стоимости](../articles/08-cost-and-service-comparison.md): ценовые сценарии, условный курс, точка безубыточности и компромиссы сервиса.
- [20 сценариев применения безлимитных токенов](../articles/09-unlimited-use-cases.md): практические примеры и эксплуатационные ограничения.

Английская версия: [Integration guides](../../guides/README.md).

Инструкции сверены с [официальной документацией Rate Cloud](https://rate-cloud.com/docs) и документацией или репозиторием каждого клиента 3 ноября 2026 года. Это статические примеры по документации, интеграции не проверялись живыми запросами. Если формат клиента изменится, следуйте актуальным инструкциям в кабинете. Примеры не содержат настоящих API-ключей и не запускают установщики или платные API-запросы.
