# Rate Cloud integration guides

Practical English setup instructions for Rate Cloud API users. Start with the guide for your client, or use the generic API guide for another OpenAI-compatible application.

- [OpenCode](opencode.md): manual provider setup for OpenCode v1, plus version guidance for v2.
- [Claude Code](claude-code.md): environment-based setup for the Rate Cloud Claude-compatible endpoint.
- [Generic HTTP and Python](http-python.md): key-free examples for curl and Python's standard library.
- [OpenClaw](openclaw.md): an OpenAI Chat Completions custom provider with environment-backed credentials.
- [Hermes Agent](hermes-agent.md): the custom endpoint configuration and key environment variable.
- [DeepSeek Harness](deepseek-harness.md): a custom OpenAI Chat Completions model API in the Web UI.
- [Continue](continue.md): a local YAML model catalog with Continue's supported secret references.
- [Fixed-price cost comparison](../articles/08-cost-and-service-comparison.md): price scenarios, dated USD prices, break-even, and service tradeoffs.
- [20 unlimited-token workflows](../articles/09-unlimited-use-cases.md): practical examples and operating boundaries.

Russian translations: [Русские инструкции](../ru/guides/README.md).

The examples were prepared against the [official Rate Cloud connection documentation](https://rate-cloud.com/docs) and each client's official documentation or repository. Sources were checked November 3, 2026. These are static documentation-based examples, not live-tested integrations. Follow the live dashboard instructions if a supported client format changes. No example contains a real API key, and the guides do not run installers or paid API requests.
