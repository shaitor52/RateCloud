Dated public data

  • Subscription periods JSON: USD display prices for each model for 3, 7 and 30 days. Three- and seven-day base prices were observed in Rate Cloud's public subscription dialog on November 3, 2026, then converted to USD using the dated public display-currency API rate. Thirty-day USD prices were retrieved from that public API. The file records source and conversion details. This is a dated display-price snapshot; confirm current prices before purchase.
  • Performance CSV: all 15 numeric values from the public five-model table, retrieved November 3, 2026. Durations are complete-request seconds; rates are effective tokens/second including waiting. Fast response means the fastest decile. Raw observations, cohort size, and measurement interval were not published alongside the table. This is not a new benchmark or a live feed.
  • Pricing JSON: dated official per-million-token text API prices and corresponding Rate Cloud 30-day subscription prices. Every provider row includes its source URL. The catalog is a selected comparison, not every vendor plan.
  • Offline calculator: 80% input / 20% output scenarios with dated USD subscription display prices and an optional input-cache-hit share. No network calls or credentials. Cache writes, tools, tax, batch rates, and special long-context tiers are excluded.

Use the cost comparison for assumptions, applicability, and caveats. A cost scenario is not a promise that a subscription can process that volume within its term.
